# 🎭 CrazyMemeCrafter — Meme Generator

A fully functional meme generator built from scratch using **vanilla HTML, CSS and JavaScript** with the **HTML5 Canvas API**. No frameworks. No dependencies. Just pure web skills.

🔗 **Live Demo:** [crazymemecrafter.netlify.app](https://crazymemecrafter.netlify.app)

---

## ✨ Features

- 🖼️ **Upload any image** — click or drag & drop
- 📋 **6 built-in meme templates** — Drake, Distracted BF, Brain, and more
- ✍️ **Draggable text** — place top & bottom text anywhere on the image
- 🔤 **Font customization** — size, style, fill color, outline color
- 🎨 **Image filters** — B&W, Sepia, Vivid, Hue Invert
- 😂 **Emoji sticker overlays** — 12 stickers to drop on your meme
- ⬇️ **One-click PNG download** — exports the final meme cleanly
- 📱 **Touch support** — works on mobile too

---

## 🛠️ Tech Stack

| Tech | Usage |
